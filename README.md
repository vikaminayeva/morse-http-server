 Конвертер азбуки Морзе (HTTP-сервис на Go).
Проект представляет собой веб-сервис (HTTP-сервер) для автоматического двустороннего перевода файлов между обычным текстом (кириллическая раскладка) и кодом Морзе. Сервис принимает файлы через HTML-форму, проводит контент-анализ строки, выполняет конвертацию, сохраняет результат локально на сервере и возвращает ответ пользователю.

##  Архитектура и технические подробности пакетов

Проект спроектирован на чистой стандартной библиотеке Go и разделен на 4 логических компонента:

### 1. `package server` (Сетевой уровень)
*   **Структура сервера:** Реализует кастомный тип, инкапсулирующий поля для логгера (`*log.Logger`) и HTTP-сервера (`http.Server`).
*   **Конфигурация HTTP-роутера:** Настраивает стандартный маршрутизатор, регистрирует эндпоинты `/` и `/upload`.
*   **Оптимизация параметров `http.Server`:**
    *   `Addr`: Запуск на порту `:8080`.
    *   `ReadTimeout`: 5 секунд (защита от медленной отправки данных).
    *   `WriteTimeout`: 10 секунд (лимит на формирование ответа).
    *   `IdleTimeout`: 15 секунд (таймаут ожидания keep-alive соединений).

### 2. `package handlers` (Уровень обработки запросов)
*   `GET /` — Считывает и отдает клиенту статический HTML-интерфейс из файла `index.html` в корне проекта.
*   `POST /upload` — Основной обработчик формы:
    1.  Парсит входящую `multipart/form-data` форму.
    2.  Извлекает файл, безопасно считывает его содержимое и гарантирует закрытие потока (`defer file.Close()`).
    3.  Передает сырые данные в слой бизнес-логики.
    4.  Генерирует локальный файл с результатом. Имя файла формируется динамически на основе временной метки (`time.Now().UTC().String()`), сохраняя оригинальное расширение через `filepath.Ext()`.
    5.  При любых сбоях корректно возвращает клиенту HTTP-статус `500 Internal Server Error`.

### 3. `package service` (Бизнес-логика / Автоопределение)
*   Анализирует входящий текст с использованием функций пакета `strings`.
*   **Умная конвертация:** Автоматически распознает тип содержимого. Если на вход подан код Морзе — декодирует его в текст. Если обычный текст — кодирует в Морзе.

### 4. `package pkg/morse` (Инфраструктурный пакет кодирования)
*   Предоставляет низкоуровневые потокобезопасные функции трансформации для русского алфавита:
    *   `ToText(morse string) string` — трансляция точек и тире в кириллицу.
    *   `ToMorse(text string) string` — трансляция кириллицы в код Морзе.

### 5. `package main` (Точка входа)
*   Инициализирует системный логгер.
*   Собирает и запускает экземпляр сервера из пакета `server`.
*   Реализует паттерн Graceful Failure: любые критические ошибки запуска перехватываются и логируются на уровне `log.Fatal`.

##  Примененный технологический стек Go

*   **HTTP Core:** Использование `net/http` для создания надежного веб-сервера без сторонних зависимостей.
*   **File I/O & Manipulation:** Потоковое чтение файлов, создание локальных копий на диске с кастомным именованием на базе `time` и `path/filepath`.
*   **Анализ данных:** Эффективная работа со строковыми слайсами и символами через пакет `strings`.
*   **Robust Logging:** Профессиональное разделение уровней логирования и централизованный контроль ошибок сервера.

##  Инструкция по локальному запуску

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Запустите HTTP-сервер:
   ```bash
   go run main.go
   ```
3. Откройте в браузере: `http://localhost:8080`
4. Для тестирования функционала используйте готовые файлы из корня проекта:
   *   Загрузите файл `test` — для перевода из Морзе в текст.
   *   Загрузите файл `test12` — для перевода из текста в Морзе.
